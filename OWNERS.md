# OWNERS

This page lists the maintainers of this repository. Maintainers review and merge pull requests, triage issues, handle security reports and approve releases.

The project has no governance document yet. `GOVERNANCE.md`, `MAINTAINERS.md` and `ADOPTERS.md` will come with a proposal to join `crossplane-contrib`, following the Crossplane [GOVERNANCE.md](https://github.com/crossplane/crossplane/blob/main/GOVERNANCE.md).
